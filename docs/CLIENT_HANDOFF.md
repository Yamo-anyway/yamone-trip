# Yamone Trip 클라이언트 인계 및 출시 게이트

이 문서는 v0.11.0 클라이언트의 재현 가능한 인계 기준이다. 현재 상태는 **안전한 로컬 클라이언트 백로그 완료 / 출시 차단**이다. 소스·단위·번들 검사가 통과해도 APK 설치, 실기기 동작, 서버 연결 또는 출시 가능을 의미하지 않습니다.

## 현재 완료 범위

- Android React Native 화면: 지역 직접 선택 → 유닛 검색·상세 → 비공개 여행·일정 → 경험 직접 체크·개인 메모.
- 한국어/영어 UI, 원문 보존 번역, 정확한 유닛 버전 스냅샷, 1–5개 안정 ID 경험 포인트.
- 비공개 로컬 유닛/불변 버전, 개선 제안, 원작·버전 출처를 보존한 파생 유닛.
- 전체 검증 후 확인하는 로컬 JSON 백업·복원과 저장 실패/동시 변경/미저장 폐기 보호.
- 실제 호출이 차단된 API/DTO mock 경계. 서버 주소·자격증명·동기화·외부 번역 호출은 없다.
- 위치·사진·광고·분석 SDK가 없는 소스 경계와 체크박스/라디오/탭 접근성 의미 구조.

## 깨끗한 환경의 소스 검사

Node.js 22 이상에서 저장소 루트 기준으로 실행한다.

```sh
npm ci
npm test
npm run check
npm run bundle:android
```

`npm run check`는 버전 일치, 한국어/영어 키, 위치·사진·외부 API 금지, 접근성 소스 규칙과 이 인계 게이트를 검사한다. `bundle:android` 결과는 APK가 아니다.

## 로컬 Android 빌드

외부 빌드 서비스나 계정 없이 JDK 17, Android Studio SDK/Build Tools, `adb`와 에뮬레이터 또는 USB 기기를 준비한다. 최종 서명 키가 아닌 개발용 디버그 APK로 먼저 검증한다.

```sh
npm ci
EXPO_NO_TELEMETRY=1 npx expo prebuild --platform android --no-install
cd android
./gradlew assembleDebug
cd ..
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

빌드 후 `android/app/build/intermediates` 아래의 **병합 manifest**를 찾아 다음을 직접 확인한다.

- `android:allowBackup="false"` 유지.
- 위치·백그라운드 위치·카메라·마이크·미디어·광고 ID 권한 없음.
- 예상하지 않은 SDK, 서비스, 리시버, 프로바이더 없음.
- `INTERNET` 권한이 있더라도 앱 실행 중 외부 요청이 없음을 트래픽 캡처로 별도 확인.

## 실기기 필수 스모크

한국어와 영어에서 각각 새 데이터로 아래를 실행하고, 실패 화면과 재현 절차를 기록한다.

1. 콜드 실행 → 지역 직접 선택 → 데모/미검증 표시 → 유닛 원문·번역 전환.
2. 비공개 여행 생성 → 정확한 버전 일정 추가 → 날짜·시간·이동·휴식 편집과 충돌 경고.
3. 경험 포인트 직접 체크 → 부분/완료/건너뜀 → 개인 메모 저장 → 앱 재시작 후 유지.
4. 유닛 초안 → 불변 버전 → 기존 일정 스냅샷 불변 → 개선 제안·파생 출처 → 번역이 파생이 아님을 확인.
5. 백업 내보내기 → 건수 미리보기 → 명시적 교체 확인 → 손상/미지원 파일이 기존 데이터를 보존하는지 확인.
6. 편집 중 Android 뒤로가기와 하단 탭 → 폐기 확인 → 계속 작성/폐기 각각 검증.
7. 소프트 키보드가 필드·저장·취소 버튼을 가리지 않고, 회전/프로세스 종료 후 거짓 저장 표시가 없는지 확인.
8. 글자 크기 기본 및 **200%**, 작은 화면, 긴 영어 문구, 시스템 내비게이션/안전 영역에서 잘림·겹침 확인.
9. TalkBack으로 제목, 필드, 체크박스 상태, 라디오 선택, 하단 탭, 오류·저장 알림의 순서와 조작 확인.
10. 시스템 설정에서 위치·카메라·마이크·사진 권한을 요청하지 않는지 확인하고 트래픽 캡처로 실제 API 호출이 없음을 확인.

## 서버 연결 결정 — 연결 전 필수

- HTTPS base URL, 인증 방식, 계정/로컬 데이터 이전 정책과 소유권 검사.
- 서버 발급 ID, revision/ETag, idempotency 보존 기간, 충돌·중단·재시도 규칙.
- 공개 유닛/비공개 여행 분리, 번역 권한·검토 상태, 신고·삭제·권리 요청과 보존 정책.
- 서버가 계산할 성장 이벤트와 악용 방지. 클라이언트 완료는 방문 인증이 아니다.
- API 스키마 승인 후 mock 하네스를 확장하고, 승인된 origin만 연결한다. 개인 메모·일정·백업은 번역 요청에서 제외한다.

## 출시 결정 — 사용자·법률·운영 검토 필요

- 최종 application ID, 앱 이름/아이콘, 버전 정책, 서명 키 보관·복구와 배포 채널.
- 출시 국가, 최소 연령, 로그인 공급자, 지도 공급자, 성장 임계치.
- 한국어/영어 이용약관·개인정보·UGC·AI 번역 안내와 국가별 법률 검토.
- 모든 SDK/네트워크/백업/보관·삭제 데이터 흐름 검토. GPS를 빼는 것만으로 법률 검토가 끝나지 않는다.
- 사진은 메타데이터 제거 파이프라인과 실제 파일 형식 회귀 검사가 구현되기 전까지 계속 금지한다.
- 광고·분석 SDK, 실제 API, 자격증명, 결제, 스토어 제출은 별도 승인과 검증 전까지 추가하지 않는다.

## 인계 판정

`docs/release-gates.json`이 기계 판독 가능한 현재 판정이다. `client_handoff_complete_release_blocked`는 서버 없는 안전한 클라이언트 구현과 인계 자료가 끝났다는 뜻이며, 출시 승인이 아니다. 남은 항목은 Android 빌드/기기 환경, 서버 구현, 사용자 제품 결정, 자격증명·서명 권한 또는 법률 검토가 있어야 진행할 수 있다.
