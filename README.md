# Yamone Trip / 야모네 트립

**v0.11.0 · 서버 없는 Android 클라이언트 인계 단계 완료. 출시·실제 API·APK 검증은 아직 차단 상태입니다.**

사용자의 “웹이 아닌 앱” 요청에 따라 React Native/Expo로 전환 중입니다. 웹뷰로 기존 사이트를 감싼 앱이 아닙니다. `native/`가 앱 화면이고 `src/`의 데이터·규칙을 재사용합니다. 이전 웹 화면은 회귀검사용으로만 보존합니다. 서버·실제 API·위치 기능·유료 빌드 서비스·스토어 제출은 포함하지 않습니다.

## 이번 앱 범위

- 한국어/영어 UI, 기기 언어 기본값과 언어 설정의 앱 내부 저장.
- 지역을 직접 선택한 후 데모 유닛 검색/상세, 1–5개 경험 포인트, 원문/데모 번역, 작성자와 버전 표시.
- 앱 저장 실패·손상 데이터·동시 변경 보호. 계정·인증·공개 게시가 아닌 비암호화 로컬 저장.
- 비공개 여행 생성, 유닛 버전 스냅샷을 일정에 담기, 날짜·시간·이동·휴식 예상 편집, 일정 겹침 경고.
- 경험 포인트 직접 체크, 부분/완료/건너뜀 상태와 개인 메모 저장. 위치나 방문 인증으로 표현하지 않습니다.
- 저장하지 않은 여행·일정·기록 입력을 두고 화면을 나갈 때 변경 폐기 확인.
- 앱과 브라우저 저장소를 분리합니다. 기존 데이터 자동 이전/삭제는 없습니다.
- 시스템 파일 선택기를 직접 눌러 로컬 백업을 내보내거나 가져옵니다. 앱은 파일을 업로드·자동 공유하지 않습니다.
- 가져올 파일 전체를 검증하고 여행/일정/경험 기록 건수만 미리 본 뒤, 별도 확인으로 현재 로컬 데이터를 교체합니다. 스냅샷과 개인 메모도 보존됩니다.
- 앱 안에서 비공개 로컬 유닛 초안을 작성하고, 원문 언어와 1–5개 경험 포인트의 안정적인 ID를 유지한 채 불변 버전으로 저장합니다.
- 새 버전을 만들더라도 기존 일정에 담긴 유닛 스냅샷은 바뀌지 않습니다. 로컬 작성은 계정·공개 게시·검증 완료를 뜻하지 않습니다.
- 원문 버전을 바꾸지 않는 비공개 개선 제안을 저장합니다. 서버나 원작자에게 전송됐다고 표시하지 않습니다.
- 파생 유닛은 새 유닛·포인트 ID를 사용하고 원작 유닛과 정확한 버전 출처를 계속 표시합니다. 번역은 파생 유닛으로 만들지 않습니다.
- 원문을 보존한 채 같은 유닛·버전·포인트 ID에 한국어/영어 번역을 저장합니다. 수동 초안·사용자 검토·AI 미검수·재검토 필요 상태를 구분하며 현재 앱은 외부 번역 API를 호출하지 않습니다.
- 추후 서버 연결을 위한 API 클라이언트·저장소 DTO 경계와 mock 검사가 준비돼 있습니다. 멱등키·리비전·인증·충돌·중단·시간초과를 검사하지만, 앱은 이 모듈을 가져오지 않고 실제 주소도 없습니다.
- 체크리스트·단일 선택·하단 메뉴에 체크박스·라디오·탭 역할과 상태를 연결했습니다. 글자 확대를 허용하고 하단 메뉴는 작은 화면에서 2열로 감쌉니다.
- Android 뒤로가기는 확인창 → 미저장 편집 → 상세 → 여행 → 기본 탭 순으로 처리합니다. 변경된 편집 내용은 명시적 폐기 확인 없이 닫지 않으며 이 순서를 순수 로직 테스트로 고정했습니다.
- [클라이언트 인계 문서](docs/CLIENT_HANDOFF.md)와 기계 판독 가능한 [출시 게이트](docs/release-gates.json)가 빌드·실기기·서버·서명·법률 결정을 완료된 소스 검사와 분리합니다.

## 개발 및 검사

Node.js 22 이상과 npm이 필요합니다. 잠금 파일 기준으로 설치합니다.

```sh
npm ci
npm test
npm run check
npm run bundle:android
```

`bundle:android`는 Android용 JS/Hermes 번들을 만드는 검사이며 APK 빌드나 화면 테스트가 아닙니다. `check`는 JSX 구문·언어 키·앱 설정·접근성 의미 구조·소스 경계를 검사합니다. 단위 테스트의 저장소는 mock이며 실제 기기의 디스크 동작을 보증하지 않습니다.

JDK/Android SDK/에뮬레이터 또는 USB 기기가 갖춰진 로컬 개발 환경에서:

```sh
npm run android
```

이 명령은 로컬 네이티브 디버그 빌드를 위한 것이며 앱 공개/스토어 제출을 하지 않습니다. 일반 개발 빌드는 Metro에 연결될 수 있습니다. 독립 실행 APK의 번들 포함·서명·오프라인 재실행·권한 검사는 별도 A03 게이트입니다. 현재 환경에는 JDK 컴파일러·Android SDK·adb가 없으므로 APK/기기 검증 완료를 주장하지 않습니다. 클라우드 빌드 계정/토큰은 필요하지 않으며 추가하지 마세요.

`npm start`는 오프라인 모드 Metro 개발 서버를 실행합니다. 앱 내부 API는 연결하지 않습니다. Expo 텔레메트리 및 앱 OTA 업데이트는 비활성 설정입니다. `app.json`의 Android 패키지 `com.yamone.trip.dev`는 개발용 임시 식별자이며 출시 식별자 확정이 아닙니다. 생성된 `android/`, 바이너리, 키/서명 파일은 커밋하지 않습니다.

참고한 공식 문서: [Expo SDK 호환성](https://docs.expo.dev/versions/v55.0.0/), [네이티브 로컬 빌드](https://docs.expo.dev/guides/local-app-development/), [AsyncStorage](https://docs.expo.dev/versions/latest/sdk/async-storage/), [파일시스템과 시스템 선택기](https://docs.expo.dev/versions/v55.0.0/sdk/filesystem/), [앱 설정](https://docs.expo.dev/versions/latest/config/app/), [언어 설정](https://docs.expo.dev/versions/v55.0.0/sdk/localization/).

## 보존된 웹 회귀 검사

```sh
npm run dev
npm run test:ui
```

`dev`는 localhost 정적 참고 화면일 뿐 새 제품 배포가 아닙니다. `test:ui`에는 Playwright/Chromium이 필요하며 네이티브 UI를 검사하지 않습니다. Chromium이 없어서 현재 브라우저 검증도 미완료입니다. 반복 다운로드나 네트워크 제한 우회는 하지 않습니다.

## 제한과 다음 단계

데모의 작성자·장소·가격·성장 표시는 실제 검증된 여행 정보가 아닙니다. 사진 업로드, 지도, GPS/위치 권한, 추적, 광고/분석 SDK, 자동 번역, 서버 인증은 없습니다. 앱 데이터 삭제나 제거 시 기록을 잃을 수 있습니다. 백업은 암호화되지 않으며 정확한 일정과 개인 메모를 포함하므로 안전한 폴더에 보관해야 합니다. OS 백업 비활성 설정은 실제 병합 manifest/기기로 다시 검증해야 합니다. 현재 데모에 대체 불가능한 개인 기록을 저장하지 마세요.

서버 없는 안전한 클라이언트 백로그와 인계 자료는 완료됐습니다. 다음 개발은 Android SDK/기기에서 A03 검증을 수행하거나, 서버·최종 패키지/서명·출시 국가/연령·지도·성장·법률 정책을 사용자가 결정한 뒤 명시적으로 재개합니다. 현재 상태와 재현 절차는 [진행 기록](docs/PROGRESS.md)과 [클라이언트 인계 문서](docs/CLIENT_HANDOFF.md)에 있습니다.
