# Yamone Trip / 야모네 트립

Client-first travel experience planner. Initial development begins with a mobile-first web client; native packaging is a later platform decision.

## Scope

- Korean and English UI; additional UI languages are out of scope.
- No device location permission, current-location detection, tracking or GPS completion proof.
- Manual region selection; public place descriptions remain separate from personal location.
- Experience units with 1–5 points; private trip schedules; local completion records.
- Original content and translations share a unit identity; versions and derivation lineage stay separate.
- Server implementation, live API connections, credentials, paid services and deployment are excluded.
- API contracts and client adapters will be prepared for a future backend.

Implementation, tests and progress checkpoints are stored in this repository. Read AGENTS.md and docs/PROGRESS.md when present before continuing.
